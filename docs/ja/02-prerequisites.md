# 2. Prerequisites (前提条件)

本ガイドの手順を実行するには、以下のいずれかのロールが必要です。

- **Enterprise owner** (Enterprise オーナー)
- **Organization owner** (Organization オーナー)
- **Billing manager** (Billing マネージャー)

対象となる Copilot プランは **Copilot Enterprise** または **Copilot Business** です。
