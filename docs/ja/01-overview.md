# 1. Overview (概要)

GitHub Copilot は、**GitHub AI Credits** (GitHub が提供する AI クレジット) を用いた **usage-based billing (使用量ベース課金、以下 UBB)** へ移行します。管理者の方は事前に利用状況レポートをダウンロードし、新しい課金モデル下での **見積コスト** を確認できます。

このレビューを支援するために、**Copilot Billing Preview** という Web アプリが提供されています。本アプリでは、ダウンロードした利用状況 **CSV をアップロード** することで分析を行います。本ドキュメントでは、このアプリの使用手順と各機能の見方を解説します。
